A deterministic UI runtime for C++

Imprint is a retained-mode GUI framework that software-rasterizes its own pixels. No timers, no threads, no hidden state: the same input sequence draws the same frame, every time — on a desktop window, a hand-held console, a terminal, or this browser tab.

There is no HTML engine in this page. The console is a 320×240 framebuffer drawn by the same C++ renderer that ships on desktop and embedded targets, compiled to WebAssembly and presented on a <canvas>. The console itself is designed in an HTML file — ids, tags, styles — which Imprint compiles into a widget tree at build time; at runtime only C++ and pixels remain.

Deterministic to the pixel

No timers, no threads, no background state. Tests record input, replay it, and compare framebuffers byte-for-byte — a UI regression is just an ordinary failing assert in CI.

Designed in HTML, rendered in C++

Screens are authored as plain HTML design files. At build time they materialize into retained-mode widget trees; the shipped binary speaks only C++.

Embeddable by contract

One small C ABI, zbapi.h, is the whole host surface: Python, a browser, a sixel terminal, a hand-held. Bring your own event loop or use the built-in shell.

The console above is the apps/showcase story — C++ plus one HTML design file — running unmodified. github.com/tyouhyou/imprint
