A deterministic UI runtime for C++

Imprint is a retained-mode GUI framework that software-rasterizes its own pixels. No timers, no threads, no hidden state: for a fixed build and buffer size, the same input sequence draws the same framebuffer bytes, every time — on a desktop window, a hand-held console, a terminal, or this browser tab. Every page below is the real framework compiled to WebAssembly; there is no DOM rendering anywhere.
