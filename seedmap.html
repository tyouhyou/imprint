TYPE any seed ENTER / DRAW regenerates MAP #N is the fingerprint

The seed text is hashed (FNV-1a) and drives a fixed LCG; the generator carves rooms, corridors and trees into a 64×48 tile grid. The same seed draws the same framebuffer bytes everywhere — the status line shows the map fingerprint, so you can compare this tab against the desktop and NDS builds byte for byte.
