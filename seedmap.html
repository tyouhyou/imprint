HOW TO PLAY type any text as a seed, press DRAW (or ENTER) SAME SEED = same map, always MAP #N is the fingerprint

A seed is just a word: the text you type is hashed (FNV-1a) and drives a fixed LCG; the generator carves rooms, corridors and trees into a 64×48 tile grid. Type a different word, press DRAW, and a different map appears — type the same word again and the exact same map comes back. The same seed draws the same framebuffer bytes everywhere — the status line shows the map fingerprint, so you can compare this tab against the desktop and NDS builds byte for byte.
