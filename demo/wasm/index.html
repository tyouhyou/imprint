Demo games — local preview

The eleven story pages in this directory, each the real framework compiled to WebAssembly. Serve this folder over HTTP (python3 -m http.server) and open a page; the published portal with the older framework demos lives on the gh-pages branch.

FOGKEEPER · 雾港灯塔

Sweep the lighthouse beam; ships only advance while lit.

COMET COURIER · 陨石快递

gravity slingshot

CRYSTAL EPOCH · 结晶纪

WINDLOOM · 织风

ROTAFARM · 转阳田

clockface farming

FIREFLY GROVE · 萤火林
